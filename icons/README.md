# Icon files needed

Since we don't have image conversion tools available, you'll need to create the following icon files manually:

1. **icon16.png** - 16x16 pixel icon
2. **icon48.png** - 48x48 pixel icon  
3. **icon128.png** - 128x128 pixel icon

You can:
1. Use the `icon.svg` file as a template
2. Convert it using online tools like:
   - https://cloudconvert.com/svg-to-png
   - https://convertio.co/svg-png/
3. Or create simple PNG icons with the letter "T" on a colored background

For now, you can copy any small PNG images to these filenames to test the extension.
